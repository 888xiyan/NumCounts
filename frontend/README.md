# NumCounts 操作员前端

这是一个零构建依赖的本地操作台，用于管理员登录、维护规则插件、创建并启用顺序工作流，以及查看一次运行的节点与底层计算记录。

先在 `backend/` 启动 FastAPI 服务，再在本目录运行：

```bash
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173`。默认后端地址为 `http://127.0.0.1:8000/api/v1`，可在登录前修改。后端示例配置已允许本地 `4173` 端口跨域访问；生产环境应将 `CORS_ORIGINS` 收紧为实际管理端地址。

节点配置和业务语义见 [规则插件与工作流设计](../doc/规则插件与工作流设计.md)。
