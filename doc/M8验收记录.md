## M8-01 技术闭环

以下真实 MySQL + FastAPI API 流程通过：

- 管理员与两个成员登录、角色边界和运行摘要访问控制；健康与就绪检查；
- 成果申报、管理员审核、仅审核通过成果进入正式核算；
- 版本化规则插件、工作流、成员试算隔离；
- 两位成员的正式结果、复核、本人查询与导出；成员不能调用管理员结果接口；
- 特殊绩效申诉：材料上传/下载、提交快照冻结、默认三天时限、受理复核、专用插件成功并生成 `approved` 成果；
- 重新正式核算创建版本 2，版本 1 仍保留；导出审计和事项事件可查询；
- 注入一条本轮唯一的中断记录，管理员恢复接口将记录与运行尝试标记失败并留下错误码；
- 最终数据库行数与测试前基线一致。
